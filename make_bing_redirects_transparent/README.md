# Make bing.com Search Redirects Transparent
Browser extension to make Bing search results transparent by setting the element alt text to the original search result urls.

At the moment, the search engine does not have a simple way to view the target URL of a search result without first clicking through the severed-up intermediate redirect link to get to the final result. This can make trusting the search results difficult since they can't be visually audited without clicking through, and by then it could be too late. Similar to looking for legitimacy in unexpected e-mails by looking at the senders' e-mail addresses, checking URLs prior to navigation can make browsing the web safer.
This extension aims to bring in URL transparency by resolving the target link URLs and displaying them in the tool-tip UI when hovering over each search result.
